Identidad y cambios

Los enlaces a cortes completos permiten consultar una versión concreta. Las ramas pueden avanzar y deben contrastarse con el corte del registro aplicable. La documentación identifica emplazamientos; no traslada código ni sustituye las fuentes canónicas. El índice completo puede consultarse en catalogo.json.

Acceso y publicación

La documentación privada conserva su control de acceso. Esta navegación pública enlaza los registros privados de forma explícita y publica únicamente fichas técnicas y resultados sintéticos seleccionados. Una ruta diferente dentro de GitHub Pages comparte el mismo origen de seguridad.

Documentación técnica de revisión. Las fichas identifican fuentes y límites; no conceden autorización ni certifican producción. Los enlaces marcados como privados requieren acceso a GitHub.
